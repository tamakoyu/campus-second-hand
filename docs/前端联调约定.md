## 2. 全局约定（前端必须遵守）

- 统一前缀：所有接口 `/api` 开头；`Content-Type: application/json; charset=UTF-8`；UTF-8。
- 统一响应：`{ code, message, data }`；`code = 0` 成功；失败时 `message` 可直接展示给用户；无数据时 `data: null`（不要省略）。
- 分页：参数 `?page=1&pageSize=10`（page 从 1 起、默认 10、最大 100）；响应 `{ list, total, page, pageSize }`。
- 金额单位：**整数「分」**，前端展示时除以 100（`BasePrice` 内置转换）。
- 时间格式：`yyyy-MM-dd HH:mm:ss`（服务器本地时区）。
- 图片：base64 字符串（含 `data:image/...;base64,` 前缀），单张 ≤ 5MB；base64 膨胀约 1.33 倍，**前端建议压缩至 1MB 内再传**。

## 3. 认证与 Token（登录模块就绪后）

- JWT Access Token：请求头 `Authorization: Bearer <accessToken>`；有效期 2 小时（开发期可放宽 24h）。
- 前端存储：localStorage；axios 请求拦截器统一注入；**HTTP 401 时清除 token 并跳转登录页**。
- 免登录白名单：`POST /api/auth/register`、`POST /api/auth/login`、`GET /api/auth/check-student`、`GET /api/products/**`（只读）、`GET /api/dicts`。
- 联调期统一 **方案 B**（陈思瀚确认）：先调 `/api/auth/login` 拿 token，请求头 `Authorization: Bearer <token>`；**不认 X-User-Id**（防伪造）。后端 `mock: true` 时 AI 接口返回稳定预设响应，认证流程与真实模型完全一致。前端联调需先准备可用测试账号（待后端提供）。

## 4. 错误码速查（axios 响应拦截器用）

| HTTP | code 段 | 场景 | 前端全局处理 |
| --- | --- | --- | --- |
| 200 | 0 | 成功 | 正常处理 |
| 400 | 400xx | 参数/业务校验 | 弹出 message |
| 401 | 401xx | 未认证/凭证错误（40100 缺失、40101 过期、40102 密码错、40103 禁用） | 清 token 跳登录 |
| 403 | 403xx | 无权限（40301 未实名、40302 信用分不足） | 弹出 message |
| 404 | 404xx | 资源不存在（40401 商品不存在/已下架） | 弹出 message |
| 429 | 429xx | 限流（42901 AI 服务繁忙） | 弹出 message + 按钮防抖 |
| 500 | 500xx | 服务端异常（50002 AI 降级——业务仍成功） | 弹出通用错误提示 |

约定：新增错误码需登记，code 全局唯一。

## 5. 超时与 AI 接口

| 位置 | 超时 | 前端处理 |
| --- | --- | --- |
| 普通业务接口（axios） | 10 秒 | 提示「请求超时，请重试」 |
| AI 接口 identify/describe/estimate/chat/review（axios） | 20 秒 | 提示「AI 服务响应较慢，请稍后重试」 |
| 推荐位 /api/ai/recommend（axios） | 10 秒 | 数据兜底，不阻塞页面 |

- **AI 问答为非流式**：`/api/ai/chat` 一次性返回 JSON（无 SSE），打字动画由前端 `setInterval` 模拟逐字输出（AiChat 组件）。
- AI 请求**失败不自动重试**，直接降级返回，保证演示流程不中断。
- 响应带 `engine` 字段：`llm`（大模型）/ `rule`（规则引擎兜底）；前端可提示「AI 服务暂不可用，已使用规则估价」。
- AI 接口均需登录（`/api/ai/review` 需 ADMIN）；**推荐位 `/api/ai/recommend` 免登录**（未登录降级热门）。

## 8. 接口速查（范胜洲相关页面）

| 页面 | 接口 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| 首页/列表 | `GET /api/products` | 免登录 | 列表/检索：`keyword`、`category`、`condition`、`minPrice/maxPrice`（分）、`sort`（latest/price_asc/price_desc/hot）、`page`、`pageSize`；仅返回在售（status=1）；无匹配返回空 list |
| 详情页 | `GET /api/products/{id}` | 免登录 | 商品详情（含 description、seller）；每次请求 views +1；不存在/已下架 → 40401 |
| 详情页 | `POST /api/ai/chat` | 登录 | AI 智能问答（**非流式**，一次性 JSON）：入参 `{productId, question, history}`，返回 `{answer, fallback, suggestManual}`；`suggestManual=true` 转人工私信（带 `?productId=&question=`） |
| 详情页/发布 | `POST /api/ai/estimate` | 登录 | 智能估价，返回 `{suggestPrice, priceRange{min,max}, reason, engine}`（金额单位分） |
| 首页/详情推荐位 | `GET /api/ai/recommend` | 免登录 | `scene=home|detail`、`productId`（detail 必填）、`limit`（默认 8 最大 20）；返回 `{items:[{id,title,price,cover,category,condition,reason}]}`；当前热门/同分类兜底，个性化待数据模块就绪 |
| 转人工私信 | 私信接口（林天楚） | 登录 | 可联调，支持可选字段 `productId`、`question`；联调期统一 Bearer（userId=1L fallback 仅临时兼容） |
