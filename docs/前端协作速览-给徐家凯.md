# 前端协作速览（给徐家凯）

> 目的：对齐**公共组件规范**与**页面样式统一**，避免第 6 周联调/中期检查阶段返工。
> 完整依据（docs/ 下三份文档，以它们为准）：《前端开发规范 v1.0》《前端公共组件清单》《前端目录结构说明》

## 0. 核心三句话

1. **样式只从全局 token 取**——所有颜色、间距、圆角、阴影走 CSS 变量，禁止在组件里写死。
2. **能用公共组件的绝不自己造**——新增组件前先查清单，组合优先。
3. **组件样式一律 scoped**——样式冲突全部收敛到全局 token，不互相覆盖。

## 1. 公共组件规范

### 1.1 组件分类与命名

| 分类 | 目录 | 命名 | 约束 |
| --- | --- | --- | --- |
| 通用组件 | `src/components/common` | `Base` 前缀（BaseCard、BaseImage） | 无业务依赖、props 驱动、可被任意页面复用、**不请求接口** |
| 业务组件 | `src/components/business` | 领域前缀（GoodsCard、SearchBar、AiChat） | 可依赖 api/store，但必须可独立使用 |

- 文件/目录 kebab-case，组件名 PascalCase，事件 kebab-case。
- props 一律做类型/必填校验，语义化命名；页面组件只做组合编排，业务逻辑进 store。

### 1.2 已有组件（13 个，按需取用）

通用：`BaseCard` `BaseEmpty` `BaseSkeleton` `BasePagination` `BaseTag` `BasePrice` `BaseImage` `BaseModal`
业务：`SearchBar` `GoodsCard` `PageHeader` `AiBadge` `AiChat` `AiPanel` `AiRecommendCard`

高频约定：商品图用 `BaseImage`（懒加载/占位/失败兜底），价格用 `BasePrice`（千分位/建议价），状态标签用 `BaseTag`，商品卡统一 `GoodsCard`。

### 1.3 新增组件流程（防重复造轮子）

1. 先查《前端公共组件清单》，能组合现有组件的优先组合。
2. 确实要新增 → 更新清单登记（名称/用途/关键 props/使用页面）+ 示例页演示。
3. 通用组件验收：空态/加载态/错误态齐全、键盘可操作（Tab/Enter/Escape）、build 无警告。

## 2. 页面样式统一（黑白极简高级感）

### 2.1 核心 token 速查

| 类别 | Token | 值 |
| --- | --- | --- |
| 主色 | `--color-primary` | `#111111`（近黑，hover/按下纯黑） |
| 主色浅底 | `--color-primary-soft` | `#F5F5F5` |
| 文字 | text-1 / 2 / 3 | `#111111` / `#555555` / `#999999` |
| 背景 | bg-page / surface / subtle | `#FFFFFF` / `#FFFFFF` / `#F7F7F7` |
| 边框/分隔 | border / divider | `#E5E5E5` / `#EFEFEF` |
| 危险 | `--color-danger` | `#E5484D`（**仅错误/删除/驳回**） |
| 圆角 | sm / md / lg / xl | 6 / 8 / 12 / 16px |
| 阴影 | md | `0 4px 12px rgba(0,0,0,.06)` |

**红线：全站禁用绿色；成功态用黑色 + ✓ 图标表达。**

### 2.2 排版与控件

- 正文 14px/22，区块标题 18px/26，详情页标题 24px/32；字重只允许 400/500/600/700（700 仅价格与关键数字）。
- 按钮：黑色实心=主操作；浅灰底=次级；白底描边=取消；红色=危险。默认高 40px、圆角 8px；一屏只留一个主按钮。
- 表单：控件高 40px、圆角 8px、聚焦 = 1px 黑边 + 3px 黑色 12% 聚焦环；错误 1px 红边 + 红字提示。
- 状态：首屏/列表用骨架屏；空态用 `BaseEmpty`；加载失败给"重试"；成功提示黑字 + ✓；危险操作（删除/下架/取消订单）走确认弹窗，按钮顺序 [取消] [确定]。
- 列表分页：每页 12 条，页码 >7 折叠，显示总数；URL 同步 `?keyword=&category=&sort=&page=`。

### 2.3 AI 元素（黑白体系）

- AI 徽标：黑底白字 "AI"（或白底黑框），**禁止彩色**。
- 用户消息气泡：黑底白字；AI 气泡：白底 + 1px 描边。
- AI 面板：顶部 2px 黑色条 + 黑色微光；底部固定免责声明"内容由 AI 生成，仅供参考，请与卖家核实"。
