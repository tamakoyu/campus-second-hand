## 1. 通用组件（components/common）

| 组件 | 说明 | 关键 Props / 事件 | 使用页面 |
| --- | --- | --- | --- |
| `BaseCard` | 通用卡片容器：标题区 + 内容区 + 操作区，统一描边/圆角/留白 | props: `title`、`extra`(右上角)、`padding`；slot: default、header、footer | 首页、列表、详情、推荐位 |
| `BaseEmpty` | 空状态：线性插画 + 主文案 + 次文案 + 主操作 | props: `image`、`title`、`description`、`actionText`；event: `action` | 列表、收藏、搜索无结果、推荐位 |
| `BaseSkeleton` | 骨架屏：列表网格 / 详情分块 / 单行三种形态 | props: `type`('grid'|'detail'|'line')、`count`、`rows` | 首页、列表、详情、AI 面板 |
| `BasePagination` | 统一分页：页码、总数、切换事件；封装 el-pagination 主题 | props: `total`、`page`、`pageSize`；event: `change(page,pageSize)` | 商品列表 |
| `BaseTag` | 统一标签：状态/分类/成色/AI 标签，语义色可控 | props: `type`('primary'|'success'|'warning'|'danger'|'ai'|'default')、`round` | 商品卡、详情、列表筛选 |
| `BasePrice` | 价格展示：现价/原价/建议价区间；数字等宽、千分位 | props: `price`、`original`、`suggest`、`size`、`bold` | 商品卡、详情、发布表单 |
| `BaseImage` | 商品图片：懒加载、占位 shimmer、失败兜底、点击预览 | props: `src`、`alt`、`lazy`、`preview`、`fallback` | 全站商品图 |
| `BaseModal` | 弹窗统一封装（el-dialog 二次封装）：标题/宽度/关闭/确认 | props: `title`、`width`、`confirmText`、`danger`；event: `confirm`、`cancel` | 确认弹窗、交易确认 |

## 3. 组件维护规则

1. 新增组件前先查清单，能组合现有组件的优先组合，不重复造轮子。
2. 通用组件进 common 必须满足：无业务依赖、props 驱动、可被任意页面复用；否则放 business。
3. 新组件需同时更新本清单（名称、用途、关键 props、使用页面），并在示例页演示。
4. 组件样式严格使用设计 token（《前端开发规范》第 2–5 节），禁止写死色值/间距。
5. 组件验收标准：props 校验完整、空态/加载态/错误态齐全、键盘可操作（Tab/Enter/Escape）、build 无警告。
