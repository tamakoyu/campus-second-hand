# 前端开发规范 v1.0

> 项目：AI 智能校园二手交易平台（前端）
> 负责人：范胜洲　|　协作：徐家凯
> 状态：v1.0 草案（待组长与徐家凯确认后定稿）
> 设计原则声明：本规范为独立定义的高质感设计系统，采用**黑白极简高级感**风格，**不参考、不沿用立项演示图（演示图-AI）的风格**，页面最终效果以本规范为准。

## 1. 设计基调与原则

整体风格：**克制、留白、清晰、可信**。黑白灰单色体系 + 精致排版，做"有高级感的交易平台"，而不是"五颜六色的电商页"。

| 原则 | 说明 |
| --- | --- |
| 克制 | 一屏一个视觉重点，全站仅黑白灰三阶，不堆砌颜色、不滥用渐变、不加无意义装饰 |
| 留白 | 区块间用足间距呼吸，卡片内容四周留白 ≥ 16px |
| 层级 | 用字重/字号/留白表达层级，少用加粗色块 |
| 可信 | 交易平台的关键是信任：一致的视觉语言、明确的反馈、克制的动效 |
| AI 适度 | AI 是能力不是装饰：AI 元素有统一标识（黑底白字徽标），与品牌同属黑白体系，靠形态与字重区分 |

色彩策略：**纯白底 + 近黑主色 + 灰阶中性色**；红色仅用于错误/危险语义；**全站不使用绿色**（含成功态，成功一律用黑色主色 + 图标表达）。

## 2. 色彩规范

### 2.1 品牌主色（近黑，承载"校园 · 简洁 · 高级"）

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--color-primary` | `#111111` | 主按钮、链接、选中态、价格主色 |
| `--color-primary-hover` | `#000000` | 主按钮 hover |
| `--color-primary-active` | `#000000` | 主按钮按下 |
| `--color-primary-soft` | `#F5F5F5` | 浅灰底（选中背景、轻提示、次级按钮底） |
| `--color-primary-border` | `#E0E0E0` | 浅灰描边（选中描边、分割强调） |

### 2.2 AI 专属标识（黑白体系，**不设独立彩色**）

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--color-ai` | `#111111` | AI 徽标文字、AI 面板头部条、推荐理由强调 |
| `--color-ai-soft` | `#F5F5F5` | AI 浅灰底（AI 面板头部、标签底） |
| `--color-ai-border` | `#111111` | AI 徽标描边（白底黑框形态时用） |

规则：AI 与主品牌共用黑白体系，**仅通过"黑底白字 AI 徽标 / 白底黑框"的形态区分**；禁止为 AI 引入紫色、蓝色等彩色，保持全站单色高级感。

### 2.3 语义色（仅保留功能性两色）

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--color-danger` | `#E5484D` | 错误、删除、驳回、信用扣分（唯一允许的彩色，仅限危险/错误） |
| `--color-warning` | `#D97706` | 待处理、审核中、提醒 |

- 成功态：**不使用绿色**，一律用主色黑 + 成功图标（如 ✓）表达。
- 中性信息提示：黑色描边/浅灰底样式。

### 2.4 中性色（文字/背景/边框）

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--color-text-1` | `#111111` | 主文字（标题、正文） |
| `--color-text-2` | `#555555` | 次级文字（说明、卖家名、时间） |
| `--color-text-3` | `#999999` | 弱化文字（占位、免责声明） |
| `--color-text-inverse` | `#FFFFFF` | 黑底上的文字 |
| `--color-border` | `#E5E5E5` | 卡片/控件描边 |
| `--color-divider` | `#EFEFEF` | 分隔线 |
| `--color-bg-page` | `#FFFFFF` | 页面底色（纯白，简洁高级） |
| `--color-bg-surface` | `#FFFFFF` | 卡片/弹窗/输入框表面 |
| `--color-bg-subtle` | `#F7F7F7` | 次级表面（悬浮操作条、hover 底、代码块） |

### 2.5 使用规则

- 所有颜色一律通过 CSS 变量引用，**组件内禁止写死色值**。
- 文本对比度：正文 ≥ 4.5:1（text-1/text-2 均满足），弱化文字仅用于辅助信息。
- 全站禁止使用绿色（含按钮、价格、成功提示、环保相关强调）；环保/减碳信息用黑白图标 + 文案表达。
- V1.0 不做暗色模式，但 token 结构按"变量化"设计，后续可平滑扩展。

## 3. 字体规范

### 3.1 字体栈

```css
--font-family: -apple-system, "SF Pro Text", "PingFang SC",
  "HarmonyOS Sans SC", "Source Han Sans SC", "Noto Sans SC",
  "Microsoft YaHei", sans-serif;
--font-family-number: "Inter", "SF Pro Text", "PingFang SC", sans-serif;
```

- 中文用系统无衬线字体栈，不引入额外字体文件（性能优先）。
- 价格、数量、统计数据使用数字字体栈，并开启 `font-variant-numeric: tabular-nums` 使数字等宽对齐。

### 3.2 字号与行高（Token）

| Token | 字号/行高 | 用途 |
| --- | --- | --- |
| `--fs-caption` | 12 / 16 | 标签辅助文字、免责声明、时间戳 |
| `--fs-aux` | 13 / 20 | 次要信息、表单帮助文案 |
| `--fs-body` | 14 / 22 | **正文基准字号** |
| `--fs-body-lg` | 16 / 24 | 商品描述、区块正文 |
| `--fs-title-sm` | 18 / 26 | 卡片标题、区块标题 |
| `--fs-title` | 20 / 28 | 页面二级标题 |
| `--fs-title-lg` | 24 / 32 | 详情页商品标题 |
| `--fs-display` | 32 / 40 | 页面一级大标题（首页 hero 区） |

### 3.3 字重与规则

- 400 正文 → 500 强调/导航 → 600 标题 → **700 仅限价格与关键数字**。
- 黑白设计中字重是核心层级工具：正文 ≥ 400，关键数字 ≥ 600。
- 禁止使用 300 及以下字重（小字号下发虚）、禁止无意义的大写中文、禁止正文使用斜体。
- 价格格式：`¥ 1,299`（整数部分千分位），建议价区间 `¥ 800 – 1,100`；金额与单位间用空格分隔。

## 4. 间距与布局

### 4.1 间距刻度（4px 基准）

```css
--space-1: 4px;  --space-2: 8px;  --space-3: 12px; --space-4: 16px;
--space-5: 20px; --space-6: 24px; --space-8: 32px; --space-10: 40px;
--space-12: 48px; --space-16: 64px;
```

- 只允许使用刻度内间距，禁止 5/7/9px 等随意值。
- 常用配对：卡片内边距 16px；列表项间 12px；区块间距 32px；页面大区块 48–64px。
- 黑白设计更依赖留白营造高级感：宁可多留白，不靠装饰填充。

### 4.2 布局

- 页面内容容器最大宽 **1200px**，两侧留白 ≥ 24px（1280 屏下体验最佳，兼容小屏笔记本）。
- 商品网格：4 列（宽屏）/ 3 列（≤1024px）/ 2 列（≤768px）。
- 页面区块结构统一为：区块标题（title-sm + 可选"更多"链接）→ 内容区 → 底部留白 32px。
- 栅格优先用 CSS Grid / Flex 语义化实现，不依赖 Element Plus 栅格硬套。

## 5. 圆角与阴影

### 5.1 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-sm` | 6px | 小控件、Tag |
| `--radius-md` | 8px | 按钮、输入框、下拉 |
| `--radius-lg` | 12px | 卡片、列表项、搜索框 |
| `--radius-xl` | 16px | 弹窗、大面板、AI 聊天面板 |
| `--radius-full` | 999px | 胶囊标签、头像、徽标 |

同一类型组件全局圆角唯一，组件内禁止各自为政。

### 5.2 阴影（黑白体系下的轻投影）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--shadow-sm` | `0 1px 2px rgba(0,0,0,.05)` | 悬浮工具条、下拉 |
| `--shadow-md` | `0 4px 12px rgba(0,0,0,.06)` | 卡片 hover、弹窗 |
| `--shadow-lg` | `0 12px 32px rgba(0,0,0,.08)` | 大弹窗、抽屉 |
| `--shadow-ai` | `0 8px 24px rgba(0,0,0,.14)` | AI 面板/入口的专属微光（黑色） |

默认卡片形态 = **1px 描边 + 无阴影（扁平）**；hover 时上浮 2px 并叠加 md 阴影。禁止彩色投影。

## 6. 按钮规范

### 6.1 层级（五级，按重要度递减）

| 层级 | 样式 | 用途 |
| --- | --- | --- |
| Primary | 黑色实心、白字 | 主操作：搜索、立即购买、确认提交 |
| Secondary | 浅灰底（primary-soft）、黑字 | 次级主操作：转人工、收藏（已收藏态） |
| Outline | 白底、1px 描边、text-1 | 辅助操作：取消、重置筛选 |
| Ghost | 无底无框、text-2 | 弱操作：更多、收起 |
| Danger | 危险红实心或描边 | 删除、下架、取消订单（配合确认弹窗） |

- 文字按钮（Link 级）用于表格内/列表内轻操作。
- **一个区域只保留一个 Primary**，避免操作层级打架。

### 6.2 尺寸与状态

| 尺寸 | 高度 | 圆角 | 场景 |
| --- | --- | --- | --- |
| sm | 32px | 8px | 紧凑场景、表格操作 |
| md | 40px | 8px | **默认** |
| lg | 44px | 8px | 首页搜索、提交页主按钮 |

- 状态：hover / active / disabled（**40% 不透明度，禁用点击**）/ loading（自带 spinner，loading 期间禁用点击）。
- 图标按钮统一 40×40 正方形，悬停加 tooltip。

## 7. 表单规范

- 输入控件统一高 40px、圆角 8px、边框 `--color-border`、聚焦时 1px 黑色边框 + 3px 黑色 12% 透明聚焦环（ring）。
- Label 14px/500，与控件间距 8px；必填项星号跟随 label；帮助文案 12px text-3。
- 错误态：1px 危险色边框 + 错误文案（12px 危险色，控件下方 4px）；校验失败时聚焦第一个错误字段并滚动到可视区。
- 禁用态：40% 不透明度 + subtle 底色，禁止交互。
- 搜索框特殊形态：圆角 999px（首页）或 12px（列表页过滤栏），高度 40–44px，内含搜索图标。
- 下拉/日期/级联等组件与输入框同高同圆角，统一 `el-input` 主题变量覆盖实现。
- 表单底部按钮：主提交 Primary + 取消 Outline/Ghost，右对齐。

## 8. 交互规范

### 8.1 加载态

| 场景 | 形态 |
| --- | --- |
| 页面首屏/列表加载 | `BaseSkeleton` 骨架屏（网格 4×3、详情页分区块） |
| 局部操作 | 按钮内 loading（spinner + 文案不变） |
| 图片加载 | `BaseImage` 占位 shimmer，加载完成后淡入 |
| AI 回答中 | AI 气泡打字动画（三点脉冲）+ 可停止 |
| 详情页 | 商品信息/卖家/推荐并行请求，各自骨架屏，不整页转圈 |

### 8.2 空态

- 统一 `BaseEmpty`：黑白线性插画 + 主文案 + 次文案 + 主操作按钮。
- 搜索无结果："没有找到相关商品" + "换个关键词试试"引导。
- 收藏为空/发布为空：对应引导按钮（去逛逛 / 去发布）。

### 8.3 错误态

- 区块级：列表加载失败 → 内嵌错误插画 + "加载失败" + 重试按钮，不整页崩溃。
- 表单内联：字段级错误文案（危险红）。
- 整页级：404 页（插画 + 回首页）。
- 统一文案风格：说人话、给出口（如"网络开小差了，请重试"），禁止裸奔报错码/堆栈。

### 8.4 成功与确认

- 成功提示：**黑色主色 + ✓ 图标**，Element Plus Message 顶部居中，2.5s 自动消失；关键交易动作（下单/收货）用成功结果视图或对话框。
- 确认弹窗：仅用于危险/不可逆操作（删除、下架、取消订单等）。按钮顺序 **[取消] [确定]**，确定按钮按危险度用 Danger 或 Primary；文案写明后果（如"下架后买家将无法再看到该商品"）。

### 8.5 滚动与分页

- 列表页：`BasePagination`，默认每页 12 条；页码 > 7 折叠；显示总数（"共 128 件"）；位置：列表底部居中。
- 首页/推荐位：横向滚动容器（隐藏滚动条，支持拖拽/箭头）。
- 长列表（私信记录、管理后台表格）按需使用虚拟滚动。
- URL 参数同步：`?keyword=&category=&sort=&page=`，刷新不丢筛选。

### 8.6 动效

- 时长 150–200ms，缓动 `cubic-bezier(.4,0,.2,1)`。
- 页面切换：160ms 淡入 + 8px 位移动画；卡片 hover 上浮 2px；列表项 hover 背景 subtle。
- 尊重 `prefers-reduced-motion`，系统要求减少动效时全部关闭。

## 9. AI 元素规范（黑白体系）

| 元素 | 规范 |
| --- | --- |
| AI 徽标 | 24px 高、圆角 6px、**黑底白字 "AI"**（或白底黑框描边形态）；禁止 emoji 充当 AI 标识，禁止任何彩色 |
| AI 推荐理由 | 12px text-3 正文 + 前置小 AI 徽标，不抢商品信息视觉 |
| AI 问答面板 | 顶部 2px 黑色条；面板背景 surface、圆角 xl、shadow-ai（黑色微光） |
| 气泡 | AI 消息左侧：白底、1px 描边、12px 圆角、8px 圆角小三角；用户消息右侧：黑底白字 |
| 输入区 | 圆角 8px、高 40px，回车发送（Shift+Enter 换行），发送中禁用 |
| 免责声明 | 面板底部 12px text-3："内容由 AI 生成，仅供参考，请与卖家核实" |
| 转人工 | Secondary 按钮 + 消息图标，携带商品 id 与当前问题跳转私信页 |
| 失败兜底 | AI 超时/失败 → 气泡内文案"AI 暂时走神了，可以联系卖家咨询" + 转人工按钮 |

## 10. 代码与命名规范

- 组件：文件/目录 kebab-case，组件名 PascalCase；通用组件 `Base` 前缀（BaseCard），业务组件领域前缀（GoodsCard、SearchBar、AiChat）。
- 页面视图：`views/<PageName>/index.vue`，页面组件大驼峰，页面内部子组件放同级目录或 `components/` 子目录。
- 样式：组件内 scoped + CSS 变量；公共组件内部类名用 BEM-lite（`.goods-card__title--highlight`）；禁止全局 id 选择器、禁止写死颜色/间距魔法值。
- JS：变量/函数 camelCase，常量 SCREAMING_SNAKE；API 函数按域命名（`goodsApi.getList()`、`aiApi.chat()`）；接口数据结构写 JSDoc 注释。
- Store：按域拆分 `useUserStore` / `useGoodsStore` / `useAiStore`，页面组件只做组合编排，业务逻辑进 store / composables。
- 网络：一切请求经 `src/utils/request.js`（统一 baseURL、10s 超时、token 头、401 跳登录、错误统一提示、解包 `{code,message,data}`）。

## 11. Git 分支与提交规范

- 分支模型：`main`（稳定）→ `dev`（集成）→ `feature/<模块>`（如 feature/goods-list、feature/ai-chat）；bug 用 `fix/<描述>`。
- 一个功能一个分支，完成后合入 dev，验收后合 main。
- 提交信息用 Conventional Commits + 中文正文：`feat(首页): 接入 AI 推荐位`、`fix(详情): 修复图片懒加载失效`；类型：feat / fix / style / refactor / docs / chore / perf。
- 合并前自查：无调试 console.log、无未使用 import、`npm run build` 通过。
